# 🕒 Ignite-Timer

A timer webpage built using **Vite**, **TypeScrip**.

## Prerequisites

Ensure you have the following installed on your machine:

- **Node.js**
- **npm**

## Getting Started

### 1. Clone repository
```bash
git clone https://github.com/Cassiano26/Ignite-timer-project.git
```
### 2. Install dependencies
```bash
npm install
```
### 3. Start the application
```bash
npm run dev
```
